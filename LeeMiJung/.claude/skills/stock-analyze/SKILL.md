## 5. 📐 ATR 기반 손절폭 산정 (필수)

**고정 % 손절은 위험**. 종목별 변동성을 반영한 ATR(Average True Range) 사용.

| 매매 스타일 | 1R 손절폭 | 사용 ATR |
|------------|----------|----------|
| **단타 (3~7일)** | 1.5 × ATR(14) | 14거래일 평균 |
| **스윙 (2~3주)** | 2.0 × ATR(14) | 14거래일 평균 |

### 적용 예시
```
종목 A (저변동): ATR(14) = ₩800 → 스윙 손절폭 = ₩1,600 (-2%)
종목 B (고변동): ATR(14) = ₩3,200 → 스윙 손절폭 = ₩6,400 (-7%)
```
→ 같은 -2% 고정 손절 시 **종목 B는 일일 변동에도 손절 발동** (잘못된 손절)

### 진입 비중 환산
- **포지션 사이즈** = (계좌 1R 한도) / (ATR 기반 손절폭)
- 예: 계좌 1,000만 원, 1R = 1% (10만 원), ATR 손절 = 4% → 매수금 250만 원

## 6. 🧭 ANALYSIS FRAMEWORK (진입 타이밍 판단 6단계)

### 1️⃣ Stage Analysis
- Stage 1 (축적) / **Stage 2 (상승) ✅ 매수 적기** / Stage 3 (분배) / **Stage 4 (하락) ❌ 매수 금지**

### 2️⃣ Multi-Timeframe Alignment
- **일봉**: 매수 셋업 형성 여부
- **주봉**: 큰 추세 방향
- 주봉·일봉이 **같은 방향** = 고확률 셋업

### 3️⃣ Setup Quality Check
- 차트 패턴 명확성, 거래량 확증, Pivot Point, RS

### 4️⃣ Catalyst & Sentiment
- 카탈리스트 식별, VIX, 외국인 수급, 섹터 모멘텀

### 5️⃣ Risk/Reward Calculation (ATR 기반)
- 손절폭 = N × ATR(14)
- 손익비 최소 1:2, 이상적으로 1:3 이상 (목표가 산정으로 측정 — 매도 전략은 출력 생략)

### 6️⃣ 진입 판정: BUY / WAIT / AVOID

## 7. 🎯 셋업 품질 점수 채점 기준 (총 100점)

| 항목 | 만점 | 기준 |
|------|------|------|
| **추세** | 25점 | Stage 2 = 25 / Stage 1 = 15 / Stage 3 = 5 / Stage 4 = 0 |
| **차트 패턴** | 20점 | 명확 = 20 / 모호 = 10 / 없음 = 0 |
| **거래량** | 15점 | 확증 = 15 / 보통 = 8 / 부진 = 0 |
| **상대강도(RS)** | 15점 | +10% 이상 = 15 / 동행 = 8 / 약세 = 0 |
| **카탈리스트** | 10점 | 강함(실적·뉴스) = 10 / 보통 = 5 / 없음 = 0 |
| **수급/심리** | 10점 | 외국인·기관 매수 = 10 / 혼조 = 5 / 매도 = 0 |
| **손익비** | 5점 | 1:3 이상 = 5 / 1:2 = 3 / 미달 = 0 |

**판정**: 80+ 강력 BUY / 65~79 분할 BUY / 50~64 WAIT / 50 미만 AVOID

## 7.5 🔒 결정론적 판정 룰 (3-Pillar)

**같은 데이터 → 같은 판정** 보장. 분석가 주관 최소화.

### Rule A — 셋업 유형 결정 (if-else, 위에서부터 첫 매칭 적용)

| # | 조건 | 유형 |
|---|------|------|
| 1 | Stage 4 | **AVOID** (분석 중단) |
| 2 | Stage 2 + `breakout_candidate=true` + `from_high > -3%` | **돌파형** (1차 = ATH×1.005) |
| 3 | Stage 2 + `from_high > -3%` + `RSI > 75` | **혼합형 (풀백 우선 + 돌파 보강)** |
| 4 | Stage 2 + `-10% ≤ from_high < -3%` + RSI 50~75 | **풀백형 (눌림목)** |
| 5 | Stage 2 + `from_high < -10%` + `vcp_candidate=true` | **풀백형 (VCP 재돌파)** |
| 6 | Stage 1 + `breakout_candidate=true` | **돌파형 (조건부)** |
| 7 | Stage 3 + `vcp_candidate=true` + 외국인·기관 5d 누적 매수 전환 | **돌파형 조건부 (MA20 돌파 시 활성화)** |
| 8 | Stage 3 + 그 외 | **WAIT (트리거 대기)** |

### Rule B — 단타/스윙 BUY/WAIT/AVOID 판정 (양쪽 독립 판정)

**단타 (3~7일)**:
- **BUY**: 셋업 점수 ≥ 65 AND `RSI < 75` AND `from_high < -3%` AND 즉시 트리거 활성 (1차 진입가 ±1% 이내 or 돌파 임박)
- **AVOID**: Stage 3·4 OR (`RSI > 85` AND `from_high > -3%`) OR 셋업 점수 < 50 OR (Stage 3 + 거래량 0.5x 미만)
- **WAIT**: 그 외 (BUY 조건 1개 이상 미충족)

**스윙 (2~3주)**:
- **BUY**: 셋업 점수 ≥ 65 AND Stage 1·2 AND `MA20 위 또는 ±1%` AND 손익비 ≥ 1:3
- **AVOID**: Stage 4 OR 셋업 점수 < 50
- **WAIT**: Stage 3 OR (셋업 점수 50~64) OR (트리거 가격 도달 대기)

**종합 진입 판정**:
- 단타 BUY + 스윙 BUY → **종합 BUY (즉시)**
- 단타 WAIT + 스윙 BUY → **분할 BUY (조건부) — 단타 WAIT / 스윙 진입 가능**
- 단타 AVOID + 스윙 BUY → **분할 BUY (조건부) — 단타 AVOID / 스윙 진입 가능**
- 단타 WAIT + 스윙 WAIT → **WAIT** (트리거 명시)
- 단타 AVOID + 스윙 WAIT → **WAIT — 단타 AVOID / 스윙 트리거 대기**
- 한쪽이라도 AVOID 핵심 사유 (Stage 4) → **AVOID**

### Rule C — 진입가·손절 앵커링 (반올림 단위 고정)

**1차/2차/3차 진입가는 반드시 다음 핵심 가격에 앵커**:

| 유형 | 1차 | 2차 | 3차 |
|------|-----|-----|-----|
| 풀백형 | MA5 + 0.5×ATR | MA5 (정확 터치) | MA20 (핵심 지지) |
| 돌파형 | ATH × 1.005 (0.5% 관통) | 1차 +2~3% (ATH ×1.025) | 1차 +5~7% (ATH ×1.05) |
| 혼합형 | MA5 + 0.5×ATR (풀백 우선) | MA5 (또는 MA20 깊은 풀백) | ATH × 1.005 (돌파 보강) |
| VCP 재돌파 | MA20 ± 0.5%(돌파 트리거 시) | 1차 +2~3% | 1차 +5% |

**손절 앵커**:
- 단타: 1차 진입가 - 1.5×ATR
- 스윙: 평균 진입가 - 2.0×ATR (또는 핵심 지지 MA20·MA60 - 0.5×ATR 중 더 보수적)

**반올림 단위 (필수)**:
- US: **$0.50** 단위 (예: $206.20 → $206.00, $213.42 → $213.50)
- KR: 가격 ₩10,000 미만 = **50원**, ₩10,000 ~ ₩100,000 = **100원**, ₩100,000+ = **500원**

### 적용 예시 (NVDA, 2026-04-24)

```
입력: Stage 2, from_high -1.85%, RSI 86.7, breakout_candidate=false, 셋업 82
Rule A: #3 매칭 → 혼합형 (풀백 우선 + 돌파 보강)
Rule B 단타: RSI 86.7 > 85 AND from_high -1.85% > -3% → AVOID 직전. 셋업 82 ≥ 65이나 트리거 즉시 활성 X → WAIT
Rule B 스윙: 점수 82 ≥ 65, Stage 2, MA20 위 ✅ → BUY
종합: 분할 BUY (조건부) — 단타 WAIT / 스윙 진입 가능 ✅
Rule C 가격:
  1차 = MA5 $202.47 + 0.5×$5.28 = $205.11 → $205.00 ($0.50 반올림)
  2차 = MA5 $202.47 → $202.50
  3차 = ATH $212.19 × 1.005 = $213.25 → $213.50
  손절 = 평균 $206.10 - 2.0×$5.28 = $195.54 → $195.50
```

## 8. ⏰ 진입 타이밍 — 다각도 검토 (필수 3개 이상)

### 관점 1: 현재가 위치 관점 ✅ 필수
**"지금 가격에서 사면 어떤가?"** — 현재가 자체의 매력도 평가.
- **52주 위치**: 상단(70%+) / 중단 / 하단(30%-) — 상단 진입은 추격, 하단은 떨어지는 칼
- **이평선 대비 위치**: 5일·20일·60일·120일·200일선 위/아래
- **신고가 대비 위치**: 신고가 -X% (조정 깊이)
- **1차 진입가까지 거리**: 현재가 vs 진입가 → 추격 매수 위험도
- **단기 등락률**: 최근 5일/20일 등락률 → 과열·과매도 판단
- **권고**: 즉시 진입 가능 / 트리거 발생 시 진입 / 조정 대기 / 추격 금지

### 관점 2: 차트 기술적 타이밍 ✅ 필수
- 패턴 완성도, 이평선 정렬, 거래량 흐름, RSI/MACD 등

### 관점 3: 수급/심리 타이밍 ✅ 필수
- 외국인·기관 순매수 추이, 공매도 잔고, 옵션 OI, VIX·Fear & Greed

### 관점 4: 이벤트/매크로 타이밍 (해당 시)
- 실적 발표일, FOMC, CPI, 옵션 만기 등 임박 이벤트

### 종합 타이밍 결론
- **공통 시그널**: 모든 관점이 동의하는 신호
- **상충 시그널**: 관점 간 엇갈리는 신호 (특히 현재가 vs 차트 셋업의 충돌)
- **최종 판단**: 즉시 / 조건부 대기 / 회피
- **타이밍 점수**: X/10

## 10. 🛑 매매 중단 룰 (Circuit Breaker) — 필수 준수

### 일일 손실 한도
| 트리거 | 조치 |
|--------|------|
| 그날 -2R 도달 | **즉시 그날 매매 종료** |
| 계좌 -3% 손실 | 의무 휴식 (다음 날까지 매매 금지) |

### 연속 패배 룰
| 트리거 | 조치 |
|--------|------|
| 3연패 | 다음 날 휴장 (관망만) |
| 5연패 | 1주일 휴장 + 매매일지 복기 |
| 월 -10% | 한 달 비중 절반 축소 |

### 정신 상태 점검
- **분노·복수 매매 감지** → 강제 종료
- **큰 수익 다음 날** → 비중 절반으로
- **외부 스트레스 (수면부족·다툼·음주)** → 매매 금지

## 11. 🧠 TRADING PRINCIPLES

- **추세 친화**: Stage 4 매수 금지
- **거래량 우선**: 거래량 없는 상승은 가짜
- **카탈리스트 의무**: 매수 이유 없으면 매수 금지
- **손익비 1:2 이상**만 진입. 미달 시 WAIT
- **ATR 기반 손절**: 고정 % 손절 금지, 변동성 반영
- **3분할 진입 의무화**: 단일 진입가 금지. 모두 3개 가격대로 분할
- **타이밍 다각도**: 차트만 본 타이밍은 위험. 현재가·수급·이벤트 관점 동시 검토
- **현재가 우선 점검**: 진입가 설정 전 항상 현재가가 어디 있는지 평가 (추격 매수·물타기 방지)
- **매매 중단 룰 절대 준수**: 일일 -2R / 3연패 / 월 -10% 시 강제 휴식
- **물타기 금지**: 손절가 이탈 시 추가 매수 절대 금지
- **No FOMO**: 이미 많이 오른 종목은 추격 매수 금지 (`from_high_pct > -3%` + RSI > 75)
- **추정치 금지**: `summary.last_date` 기준 명시
- **핵심 요약 밀도**: 첫 요약은 단순 한 줄 결론이 아닌, 국면·스타일·가격·타이밍·리스크 압축한 4~6문장 단락

## 13. 출력 규칙

- **압축 원칙**: 핵심 요약 각 줄은 1문장(쉼표 1개 이내), 카탈리스트 각 항목은 1~2줄 한 호흡. 중복 표현·수식어·평가 코멘트 금지. 핵심 요약과 카탈리스트 상세 간 정보 중복 회피.
- **결정론 원칙 (Section 7.5)**: Rule A(셋업 유형) → Rule B(단타·스윙 판정) → Rule C(가격 앵커링) 순서로 기계적 적용. 같은 데이터는 같은 진입가·판정 산출.
- **출력 금지**: 진입 타이밍 다각도(4관점) · 단타/스윙 상세 시나리오 블록 · 매도 전략(익절·본전·시간·체크·Hard Exit·트레일링) · 차트 진단 · 리스크 상세 섹션 · 매매 중단 룰
- 가격 정밀도: US 소수점 2자리 / KR 1원 단위
- WAIT 재검토 트리거 가격은 명시 (BUY/AVOID 전환 조건)
