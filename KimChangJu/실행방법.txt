CM 패키지 관리 앱 — 실행 방법
================================

1. 이 압축을 원하는 폴더에 풀어주세요.
2. index.html 파일을 더블클릭하면 Chrome, Edge, Firefox 등 브라우저에서 바로 실행됩니다.
   (별도 설치나 서버 없이 동작하는 순수 HTML/자바스크립트 앱입니다.)
3. 달력에서 날짜를 클릭 → 그날의 CM 패키지 목록 확인 → 목록 항목 클릭 또는
   "신규 등록"으로 하단 상세 입력 폼에서 패키지를 등록/수정할 수 있습니다.
4. 입력한 데이터는 브라우저의 localStorage에 저장되어, 새로고침하거나
   브라우저를 껐다 켜도 같은 브라우저·같은 PC에서는 유지됩니다.
   (다른 PC나 다른 브라우저로는 데이터가 옮겨가지 않습니다.)

포함된 파일
------------
- index.html                    : CM 패키지 관리 앱 본체
- CM관리매니저기능설명.pptx      : 달력·목록·상세내역·알림 4개 기능 설명 프레젠테이션
