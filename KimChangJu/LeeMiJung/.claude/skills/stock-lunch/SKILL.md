# 점심 장중 트레이딩 노트 전송

전문 트레이더 톤. 종목 추천은 반드시 실명 + 종목코드.

## 1. 시장 정보 수집

Bash로 스크립트를 실행하세요:
```bash
/Users/ghyu/Repositories/Claude/LMJAgent/.venv/bin/python3 /Users/ghyu/Repositories/Claude/LMJAgent/.claude/shared-scripts/market-fetcher.py --market --stocks 010950,000660,012450,003490,096770,078930
```

JSON 결과에서 `korean_indices`(코스피/코스닥), `us_futures`(S&P선물), `fx`(원/달러), `stocks`(종목 현재가) 데이터를 사용하세요.
스크립트가 실패하거나 데이터가 부족한 경우 WebFetch를 폴백으로 사용하세요.

추가로 수집 필요:
- 수급: 코스피/코스닥 외국인/기관/개인 (WebSearch/WebFetch)
- 장중 주도 테마 흐름
- 신규 관심 종목 1개
- 오후장 주의사항 2~3가지

## 2. 메시지 작성 (텔레그램 모바일 가독성 우선)

- 구분선은 짧게 (━×12)
- **표 만들지 말 것** — 한 줄 인라인으로 (예: `외인 -170 · 기관 +406 · 개인 -240`)
- 들여쓰기 최소화
- 섹션 사이는 빈 줄 1개

날짜는 `date '+%-m/%-d'`. 등락은 ▲▼.

본문 템플릿:
