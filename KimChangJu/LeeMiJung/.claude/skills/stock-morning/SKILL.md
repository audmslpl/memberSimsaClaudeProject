# 아침 모닝 브리핑 전송

전문 트레이더 톤. 모든 수치는 실제 데이터 수집. 종목 추천은 반드시 실명 + 종목코드.

## 1. 시장 정보 수집

Bash로 스크립트를 실행하세요:
```bash
/Users/ghyu/Repositories/Claude/LMJAgent/.venv/bin/python3 /Users/ghyu/Repositories/Claude/LMJAgent/.claude/shared-scripts/market-fetcher.py --market
```

JSON 결과에서 `us_indices`, `us_futures`, `macro`, `fx`, `sectors` 데이터를 사용하세요.
스크립트가 실패하거나 데이터가 부족한 경우 WebFetch로 finviz.com, investing.com 등을 폴백으로 사용하세요.

추가로 수집 필요:
- 오버나잇 서머리 2~3줄 (WebFetch/WebSearch)
- 오늘밤 미국 일정 (WebFetch: investing.com/economic-calendar/)
- 주도 테마 TOP3 (한국 대표주 실명 + 코드)
- 약세 경계 테마
- 매수 추천 3종목 / 매도·비중축소 2종목

## 2. 메시지 작성 (텔레그램 모바일 가독성 우선)

- 구분선은 **짧게** (━×12) — 모바일 폭 초과 금지
- **표 만들지 말 것** — 텔레그램은 비례 폰트라 컬럼이 정렬 안 됨. 한 줄에 인라인으로 (예: `외인 -170억 · 기관 +406억 · 개인 -240억`)
- 들여쓰기 최소화 (앞 공백 X)
- 섹션 사이는 빈 줄 1개로 분리
- 이모지를 섹션 마커로 활용

날짜는 `date '+%-m/%-d (%a)'`. 등락은 ▲▼.
